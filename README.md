# Porquinho Inteligente

Um aplicativo web simples para controlar seu salário, ganhos extras, despesas fixas e variáveis mensais.

## Como usar

1. Abra `index.html` no navegador.
2. Informe seu salário e seus ganhos extras.
3. Adicione despesas fixas e despesas variáveis.
4. O resumo mostra a renda total, os gastos e a economia líquida.
5. Os dados são salvos no `localStorage` do navegador para continuar usando depois.

## Funcionalidades

- Controle de salário e ganhos extras.
- Cadastro de despesas fixas e variáveis.
- Cálculo automático de economia líquida.
- Remoção de despesas.
- Limpar todos os dados.

---

Pronto para usar: abra o arquivo `index.html` e comece a controlar seu porquinho inteligente.
